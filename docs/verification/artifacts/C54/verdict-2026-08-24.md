# C54 闭合留证 — 2026-08-24

## 1. 根因不是"告警太吵",是**比错了对象**

`cdr.go` 拿 **我们的数**(来自 `billedLeg` 选中的那条腿)去比 **交换机对 originator 腿的数**。
两者在呼入、以及本平台自己置的呼上是同一条腿;**坐席外拨时是两条不同的腿** ——
坐席自己的话机 auto-answer,交换机因此对他那条腿从头计费(响铃 30 秒也算),
而我们计费的是**面向运营商的那条腿**:没人接,就是 0。

所以它在**每一通未接的 click-to-dial** 上必响,而账本每一次都是对的。

```

tech={"callerChannelId": "91515cb6-…"}       ← switchBillSec 不再出现
```

`tech.switchBillSec` 在内线/未接外拨上**消失**是预期的:那是拿一条没人计费的腿去做比对,
不是数据缺失。(`ledger.yaml` 里唯一断言该键的是 VC-S14-04 的**外线一型**,不受影响。)

## 4. 为什么不是"把告警关小"

**C49 正是被这条噪声盖住两天没人读的** —— 每一通 AI 外呼都计费为 0、交换机说 21,
这条告警天天在喊,而喊的同时它也在为正常的通话喊。

所以修法是**比同一条腿**,不是加静音条件:
AI 外呼上被计费的腿**就是** originator,C49 那一类仍在监视之下。
彻底没人计费的场合(两部分机通话)才没有可核对的主张,此时整块跳过。
