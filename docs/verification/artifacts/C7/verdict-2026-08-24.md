## 4. 权限:主管专属,且是刻意的

```
坐席 wei 读同一条    -> 403 {"code":"FORBIDDEN","params":{"requiredRole":"SUPERVISOR"}}
主管读没排过队的通话 -> 200 {"items":[]}
```

这些行**点名了这通电话曾派给哪些同事、谁没接** —— 正是"一条腿的事件只发给它自己的坐席"
那条指令要挡在坐席视野之外的东西。空数组是**答案**不是缺失:没进过队列的通话没有旅程。
